# Memory Bloom

MASTER DESIGN SPECIFICATION

PART 1A — FOUNDATION & CREATIVE DIRECTION

PROJECT NAME

A Letter for Your Next Chapter

Tagline

Every memory is a page. Every smile is a new beginning.

PROJECT VISION

This website is not simply a birthday website.

It is an interactive digital story.

The experience should make the recipient feel as if they are opening a beautifully handcrafted gift that slowly transforms into a magical journey through memories, emotions, and hopes for the future.

The goal is not to impress with flashy animations.

The goal is to create emotion.

The user should smile naturally while exploring.

Every interaction should feel warm.

Every animation should have meaning.

Every scene should tell part of the story.

DESIGN PHILOSOPHY

The website must never feel like multiple pages connected together.

Instead,

it should feel like one uninterrupted cinematic journey.

Every section flows naturally into the next.

No harsh cuts.

No obvious page breaks.

Scrolling represents moving forward through memories.

DESIGN PRINCIPLES

1. Less, but Better

Never add decorations simply because there is empty space.

Whitespace is part of the design.

Leave breathing room.

2. Motion Must Have Purpose

Every animation answers one question:

"Why is this moving?"

If no meaningful answer exists,

remove the animation.

3. Story First

The story is more important than the animation.

The animation exists to support the emotion.

Never the opposite.

4. Typography Is The Hero

Illustrations decorate.

Animations guide.

Typography communicates.

The text is always the primary focus.

5. Consistency

Never mix

Photo

↓

Anime

↓

Realistic

↓

Flat SVG

↓

3D

Choose one illustration language.

Use it everywhere.

LOADING SCREEN

Do not use a spinner.

"Preparing something special..."

Ribbon unties automatically.

Fade into Hero Section.

SCROLL PHILOSOPHY

Scrolling should never feel mechanical.

The user should feel like they are gently moving through a storybook.

Every section transition must be connected through shared visual elements.

For example:

 Floating petals continue into the next section.

 Lighting shifts gradually instead of changing abruptly.

 Decorative particles persist briefly across transitions.

 Motion eases in and out naturally.

MOTION PRINCIPLES

Every animation must follow these rules:

 Slow in, slow out.

 Use easing that feels organic, not robotic.

 Avoid exaggerated bouncing.

 Small secondary motions are better than large dramatic ones.

 Idle animations should be subtle enough that users notice them only after a few seconds.

MICRO INTERACTION RULES

Interactive elements should respond softly:

 Buttons lift by a few pixels on hover.

 Cards tilt slightly toward the cursor.

 Decorative particles react gently to mouse movement.

 Images brighten slightly instead of scaling aggressively.

 Audio controls fade in rather than popping into view.

QUALITY CHECKLIST (FOUNDATION)

Before moving to the next section, every page should satisfy these questions:

 Does the layout have enough breathing room?

 Is the typography still the visual focus?

 Are all illustrations in the same style?

 Does every animation have a purpose?

 Is the color palette consistent?

 Does the page feel calm rather than busy?

 Would removing one decorative element improve the composition?

If the answer to the last question is "yes", simplify the design.
